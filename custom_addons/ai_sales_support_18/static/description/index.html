Auto Quotation

Generate professional quotations automatically with AI assistance

🔄 Workflow Process

1
Sales team sends product inquiry to AI system
2
AI analyzes and extracts product information using ChatGPT
3
System checks inventory and pricing in Odoo database
4
If sufficient stock: Generate quotation immediately
5
If insufficient stock: Contact suppliers via Zalo OA
6
AI processes supplier responses and generates final quotation

📋 Requirements

ChatGPT API key from OpenAI
Zalo OA account with verified user IDs for suppliers
Odoo 18 with Sales, Inventory, and Website modules
Configured supplier contacts with Zalo user IDs
