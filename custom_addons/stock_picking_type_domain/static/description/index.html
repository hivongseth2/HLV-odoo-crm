Stock Picking Type Domain Filter

Giới hạn loại hoạt động theo ngữ cảnh

Tính năng chính

Module này giúp bạn giới hạn các loại hoạt động (picking type) hiển thị trong stock.picking dựa trên ngữ cảnh và nguồn gốc của picking.

  • Bán hàng: Chỉ hiển thị Lấy hàng, Gói, Lệnh giao hàng
  • Mua hàng: Chỉ hiển thị Phiếu nhập kho
  • Chuyển hàng nội bộ: Chỉ hiển thị Lệnh chuyển hàng nội bộ

Lợi ích

Giao diện rõ ràng

Giảm nhầm lẫn khi chọn loại hoạt động

Dễ sử dụng

Nhân viên chỉ thấy các tùy chọn phù hợp

Tự động

Domain filter được áp dụng tự động

Cài đặt đơn giản

  1. Copy module vào thư mục custom_addons
  2. Cập nhật danh sách Apps trong Odoo
  3. Cài đặt module "Stock Picking Type Domain Filter"
  4. Sử dụng ngay lập tức!
